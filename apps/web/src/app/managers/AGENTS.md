# Domain managers

Keep state, commands, subscriptions, lifecycle, persistence, context and hooks together by domain. UI-library adapters belong in a domain's adapter subdirectory; user-facing UI belongs in components/ or its feature. environment/ exposes the business snapshot { shell, chrome } from the document’s ChromeAdapterProvider. Window state, geometry and DOM props live in platform/chrome-adapter. Core environment code contains no host protocol implementation. VisualManager remains the single authority for appearance; adapters consume it rather than creating another preference store.

Prepaint and VisualManager's first connection select the first valid record from native, SSR cookie and local storage, in that order. After a commit or first connection, reconcile the maximum observed record across those replicas and memory. Keep request seeds in the server snapshot and adopt the read-only prepaint handoff during render. Re-read Web targets before repair. Actions, including single-field and whole resets, commit sparse records. Report failures per store and guard native push completions by their owning operation.
